# 番茄专注 TomatoFocus

一个轻量的 Windows 桌面番茄钟。**单个 exe，约 170 KB，零运行时依赖**（Win10/11 自带 .NET Framework 4.8），
所有界面、图形、动效、音效**全部由代码程序化生成**，不依赖任何图片或音频文件。

---

## 快速开始

```powershell
powershell -File build.ps1 -Run      # 编译并启动
powershell -File build.ps1 -Test     # 编译并跑测试（289 项）
powershell -File build.ps1 -Sheet    # 渲染界面快照到 build\dev\snapshots\
```

产物：`dist\TomatoFocus.exe`（**交付目录里只有这一个 exe**；测试程序与快照都在 `build\dev\`）

## 番茄怎么算

一颗番茄 = **10 格**；25 分钟 = 1500 秒 = 10 格，即 **1 格 = 150 秒**。全部整数运算，无浮点误差。

| 情形 | 公式 | 例 |
|---|---|---|
| 正常完成 | `格数 = 专注秒数 ÷ 150` | 25 分 → 1.0 颗；30 分 → 1.2 颗（1 完整 + 0.2 碎片） |
| **提前中断** | `格数 = 专注秒数 ÷ 300`（**收益减半**） | 20 分中断 → 0.4 颗；不满 0.1 颗**不记录** |

**钱包规则**

- **完整颗**（`总格数 ÷ 10`）才是可兑换货币
- **碎片**（`总格数 % 10`）不可兑换，但会持续累积；**攒满 1.0 颗自动转为 1 颗完整番茄**，恢复正常兑换
- 兑换只扣完整颗，余额永不为负

所有会话（含中断）都**如实记录**，日历与日详情中用斜纹/琥珀色番茄区分中断收益。

## 功能一览

| 模块 | 说明 |
|---|---|
| 计时 | 档位 5 / 15 / 25 / 自定（1–180 分）；**点档位只选时长，点「开始」才计时**；暂停不计时；检测系统休眠自动暂停 |
| 日历 | 月视图 + 年视图热力图，格内显示当日番茄总数，中断日有标记，点选查看当日明细 |
| 成就 | 20 项（累计量 / 单日最高 / 连续天数 / 单次最长 / 时段 / 完整性 / 碎片转正 / 健康习惯） |
| 奖励 | 称号 · 奖章 · 主题 · 动效 · 提示音，全部用完整番茄兑换 |
| 托盘 | 4 种状态不同配色；悬停显示剩余时间；右键菜单含全部功能 |
| 极简模式 | 窗口收纳进托盘，功能只在右键菜单里提供；双击托盘图标可临时唤出窗口 |
| 开机自启 | 写入 HKCU 的 Run 项，无需管理员，**默认关闭** |
| 关怀提醒 | 每个专注区间结束弹出起身活动卡片，42 条关怀语句随机轮换 |
| 国际化 | 默认简体中文；文案全部在 `Lang/*.json`，英文版只需补文件 |
| 图片接口 | `assets/` 放图即替换程序化绘制，删图即回退，支持热重载 |

### 快捷键

`空格` 开始/暂停 · `1`/`2`/`3` 选择 5/15/25 分钟 · `C` 自定（在档位格子内直接输入分钟数，回车确认，点击别处取消） · `T` 回到今天 · `←`/`→` 翻月 · `Esc` 暂停或收起抽屉

> 修复记录见 `FIXES.md`。

## 健康依据

提醒规则参考以下公开建议，设置页内可查看：

- [世界卫生组织《身体活动与久坐行为指南》](https://www.who.int/publications/i/item/9789240015128) —— 所有年龄组都应限制久坐时间，用任何强度的活动替代久坐；成人每周 150–300 分钟中等强度活动
- [《健康中国行动（2019—2030 年）》](https://www.nhc.gov.cn/guihuaxxs/c100133/201907/2a6ed52f1c264203b5351bdbbadd2da8.shtml) —— 全民健身行动、职业健康保护行动
- [《中国居民膳食指南（2022）》准则六](http://dg.cnsoc.org/article/04/wDCyy7cWSJCN6pwKHOo5Dw.html) —— 主动喝水、少量多次，每次约 200 毫升
- [美国验光协会（AOA）](https://www.aoa.org/healthy-eyes/eye-and-vision-conditions/computer-vision-syndrome) —— 20-20-20 规则；连续用电脑 2 小时后休息 15 分钟

所有提醒**都可跳过、可延后，不指责、不惩罚**。

## 目录结构

```
src/Core/     计量、存储、统计、成就、奖励、健康规则、音效、Win32
src/App/      计时引擎、状态门面、主窗口、外壳、快照渲染
src/Ui/       全部界面（即时模式，单窗口零弹窗）
src/Render/   绘图原语、缓动/弹簧/粒子、配色主题
src/Render/Art/  程序化番茄、图标、奖章
src/Tray/     托盘控制器、程序化托盘图标、ICO 打包
src/Assets/   图片接口（manifest + 热重载 + 回退）
Lang/         语言包（编译期嵌入，也可放在 exe 同目录覆盖）
assets/       可选的图片覆盖槽位
tests/        测试运行器与 233 项断言
```
