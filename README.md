# 🍅 番茄专注 TomatoFocus

一个**轻到离谱**的 Windows 桌面番茄钟：单个 exe，双击就用，什么都不用装。

界面、番茄、奖章、音效**全部由代码画出来**——没有一个图片文件，也没有一个音频文件。

> 🌐 仓库：https://github.com/FishShitMan/TomatoFocus
> 📦 单文件约 300 KB · Win10 / Win11 自带运行库，无需额外安装 · 纯本地不联网

---

## 🚀 三步开吃

1. 下载 `番茄专注.exe`
2. 双击
3. 挑个时长，点「开始」🍅

- 关闭窗口默认**收进托盘**；右键托盘图标可开始 / 暂停 / 退出
- 想先试试又不影响现有数据：`番茄专注.exe --data "D:\tf-test"`

## ⏱ 它能做什么

| | |
|---|---|
| 🍅 **专注计时** | 5 / 15 / 25 / 自定（1–180 分钟），默认 5 分钟起步；点档位只是选时长，点「开始」才计时；电脑睡眠回来会自动暂停 |

| 📅 **日历回顾** | 月视图 + 年视图热力图，一天几颗一眼看穿；点开看当天明细，中断的那颗用琥珀色标出来 |
| 🏆 **20 项成就** | 累计、单日最高、连续天数、时段、碎片转正……总有一款在等你解锁 |
| 🎁 **奖励商店** | 称号 / 奖章 / 主题 / 动效 / 5 种提示音，全部用「完整番茄」兑换 |
| 📝 **随手笔记** | 边专注边记要点，中文输入法直接可用；本轮结束随番茄一起存进当天记录 |
| 🌤 **温馨问候** | 早、午、下午、深夜各问候一次，不打断专注，12 秒自己消失 |
| 🔔 **久坐关怀** | 每轮结束弹一张起身卡片，44 条关怀语句随机轮播；能跳过，也能延后 |
| 🖥 **托盘四色** | 待机橙 · 专注红 · 暂停黄 · 休息绿，扫一眼就知道在干嘛 |
| 🌙 **极简模式** | 窗口收进托盘，功能全在右键菜单里 |
| 💾 **崩溃恢复** | 计时状态每秒存一次（1 KB），崩溃、强杀、手滑结束进程，重开都能接着走 |

> 最短路径只有三步：**开始 → 专注完 → 起来活动一下**。其它功能，用得到再说。

## 🍅 番茄怎么算

一颗番茄 = **10 格**，25 分钟 = 1500 秒 = 10 格，也就是 **1 格 = 150 秒**。

| 情形 | 算法 | 例子 |
|---|---|---|
| 老老实实跑完 | 专注秒数 ÷ 150 | 25 分钟 → 1.0 颗 |
| 中途放弃 | 专注秒数 ÷ 300（**半收益**） | 20 分钟 → 0.4 颗 |

- 只有**整数颗**能拿去兑换；**碎片**会一直攒着，攒满 1 颗自动变整颗 ✨
- 不满 0.1 颗的中断不记账；所有会话都会如实写进日历

## ⌨️ 快捷键

`空格` 开始 / 暂停 · `1` `2` `3` 切 5 / 15 / 25 分钟 · `C` 自定（直接输分钟数，回车即开始）· `T` 回到今天 · `←` `→` 翻月 · `Esc` 暂停或收起侧栏

## 🛟 遇到问题了？

主界面**左上角番茄连点 5 次** → 点「导出诊断报告」→ 报告会自动打开，复制发出来就行。
里面含版本、系统、输入法状态、渲染统计和最近日志——定位问题基本靠它。

---

## 🔒 数据与隐私

- 数据在 `%APPDATA%\TomatoFocus\`（原子写入 + 自动备份），删掉这个文件夹即彻底卸载
- 设置页支持导出 / 导入 JSON
- **纯本地、不联网、不上传任何东西**

## 🧑‍💻 想自己改？自己编？

```powershell
powershell -File build.ps1 -Run      # 编译并启动
powershell -File build.ps1 -Test     # 编译并跑全部测试（952 项）
powershell -File build.ps1 -Sheet    # 渲染界面快照
```

产物是 `dist\TomatoFocus.exe`；测试程序与快照在 `build\dev\`。

```
src/Core/        计量、存储、统计、成就、奖励、健康规则、音效、Win32
src/App/         计时引擎、状态门面、主窗口、外壳
src/Ui/          全部界面（即时模式、单窗口、零弹窗）
src/Render/      绘图原语、缓动/粒子、配色主题、程序化番茄
src/Tray/        托盘控制器、程序化托盘图标
Lang/            语言包（编译期嵌入，也可放 exe 同目录覆盖）
tests/           测试运行器（952 项断言）
```

> 📌 版本改动见 `RELEASE-<版本>.md`；更细的缺陷修复清单维护在仓库之外。
