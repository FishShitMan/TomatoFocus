# 番茄专注 TomatoFocus

> Github仓库：https://github.com/FishShitMan/TomatoFocus

一个轻量的 Windows 桌面番茄钟。**单个 exe，约 247 KB，零运行时依赖**（Win10/11 自带 .NET Framework 4.8），
所有界面、图形、动效、音效**全部由代码程序化生成**，不依赖任何图片或音频文件。

---

## 快速开始

```powershell
powershell -File build.ps1 -Run      # 编译并启动
powershell -File build.ps1 -Test     # 编译并跑测试（721 项）
powershell -File build.ps1 -Sheet    # 渲染界面快照到 build\dev\snapshots\
```

产物：`dist\TomatoFocus.exe`（**交付目录里只有这一个 exe**；测试程序与快照都在 `build\dev\`）

## 番茄怎么算

一颗番茄 = **10 格**；25 分钟 = 1500 秒 = 10 格，即 **1 格 = 150 秒**。全部整数运算，无浮点误差。

| 情形 | 公式 | 例 |
|---|---|---|
| 正常完成 | `格数 = 专注秒数 ÷ 150` | 25 分 → 1.0 颗；30 分 → 1.2 颗（1 完整 + 0.2 碎片） |
| **提前中断** | `格数 = 专注秒数 ÷ 300`（**收益减半**） | 20 分中断 → 0.4 颗；不满 0.1 颗**不记录** |

**钱包规则**

- **完整颗**（`总格数 ÷ 10`）才是可兑换货币
- **碎片**（`总格数 % 10`）不可兑换，但会持续累积；**攒满 1.0 颗自动转为 1 颗完整番茄**，恢复正常兑换
- 兑换只扣完整颗，余额永不为负

所有会话（含中断）都**如实记录**，日历与日详情中用斜纹/琥珀色番茄区分中断收益。

## 功能一览

| 模块 | 说明 |
|---|---|
| 计时 | 档位 5 / 15 / 25 / 自定（1–180 分），**默认最低档 5 分钟**；**点档位只选时长，点「开始」才计时**；暂停不计时；检测系统休眠自动暂停 |
| 自定档位 | 会话级：每次启动/关闭都回到「自定」；点开自定栏后时间环显示 **00:00**，输入数字**实时同步**，随后**按回车或直接点「开始」即开始倒计时**（无需两步确认）；未输入时点「开始」不动作 |
| 休息档位 | 主动开始休息用：5 / 10 / 15 / 自定，默认最低档 5 分钟；与设置里的「休息时长」互不影响 |
| 日历 | 月视图 + 年视图热力图，格内显示当日番茄总数，中断日有标记，点选查看当日明细；**鼠标悬停时整格填充实心色块、文字与番茄反色剪影** |
| 成就 | 20 项（累计量 / 单日最高 / 连续天数 / 单次最长 / 时段 / 完整性 / 碎片转正 / 健康习惯） |
| 奖励 | 称号 · 奖章 · 主题 · 动效 · **5 种提示音**（默认双音 / 清脆铃音 / 柔和低吟 / 水滴 / 木叩），全部用完整番茄兑换；**勋章带扫过的动态高光，彩色勋章在 5 套配色方案间循环，未解锁勋章灰显且静止** |
| 笔记 | 主界面即可记录本轮要点，**支持中文输入法**（聚焦时自动切到中文布局并打开输入法，拼音组合窗口与候选框跟随光标），内容随本次番茄一起保存 |
| 托盘 | **待机橙 · 专注红 · 暂停黄 · 休息绿**四态配色（不随主题漂移，一眼可辨）；悬停显示剩余时间；右键菜单**以鼠标为原点向右展开**，含全部功能 |
| 极简模式 | 窗口收纳进托盘，功能只在右键菜单里提供；双击托盘图标可临时唤出窗口 |
| 开机自启 | 写入 HKCU 的 Run 项，无需管理员，**默认关闭** |
| 关怀提醒 | 每个专注区间结束弹出起身活动卡片，42 条关怀语句随机轮换；设置里的「休息时长」（5/10/15/20 分钟）**只影响这张卡片建议的休息时间**；卡片的「**保留笔记**」会把上一轮保存的笔记恢复到草稿，方便在原内容上继续续写 |
| 温馨问候 | 早起 05:00–09:00 / 午间 11:30–13:30 / 下午 14:00–17:30 / 夜深 22:30–05:00 四个时段各问候一次；**不打断专注**（计时中自动延后），12 秒自动消失，窗口在托盘时改走系统气泡；设置里可关（默认开） |
| 国际化 | 默认简体中文；文案全部在 `Lang/*.json`，英文版只需补文件 |
| 图片接口 | `assets/` 放图即替换程序化绘制，删图即回退，支持热重载 |

### 快捷键

`空格` 开始/暂停 · `1`/`2`/`3` 选择 5/15/25 分钟 · `C` 自定（在档位格子内直接输入分钟数，**回车即开始**，点击别处取消） · `T` 回到今天 · `←`/`→` 翻月 · `Esc` 暂停或收起抽屉

### 排查与自检

**遇到问题想反馈？** 主界面**左上角番茄图标连点 5 次** → 点「**导出诊断报告**」→ 报告会写到桌面并自动打开，复制发回即可。报告含版本、系统、输入法状态、渲染统计与最近日志。

命令行方式：

- `番茄专注.exe --perf 12` —— 依次跑「空闲 / 动画 / 计时」三段真实场景，把帧间隔分布、单帧绘制耗时、CPU 占比与**绘制分段明细**写到数据目录下的 `perf.txt`（主程序是窗口程序、没有控制台输出）
- `番茄专注.exe --ime` —— 打印窗口的输入法上下文、打开状态、转换模式与已安装键盘布局，并模拟一次「笔记聚焦」；中文输入有问题时把这份输出发回来即可定位
- `番茄专注.exe --frames-log` —— 每秒把帧统计（快路径/整窗帧数、当前档位、空闲秒数）写进日志，用于验证「无操作降档」

### 渲染机制（为什么常驻动效也流畅）

整窗重绘一帧约 14ms，所以任何动画都会强制整窗刷新、帧率只能压低。为此程序有一条**勋章快路径**：整窗绘制后把这一帧用 `BitBlt` 存进缓存位图，当**只有勋章在变**时改为「贴缓存 + 只重画那几枚勋章」（首页顶栏一枚；奖励页再加上列表里已拥有的几枚，并按可见区裁剪），单帧降到约 3.8ms，常驻动效因此能跑 30fps。交互/计时/状态变化时仍走整窗重绘。

常驻动效的帧率还跟**前台状态**与**操作空闲**挂钩：

| 状态 | 常驻动效 |
|---|---|
| 窗口不在前台 | 不跑（零重绘） |
| 前台 + 10 秒内有操作 | 30fps |
| 前台 + 连续 10 秒无操作 | 约 6fps（任意鼠标/键盘操作立即恢复） |

提醒规则参考以下公开建议，设置页内可查看：

- [世界卫生组织《身体活动与久坐行为指南》](https://www.who.int/publications/i/item/9789240015128) —— 所有年龄组都应限制久坐时间，用任何强度的活动替代久坐；成人每周 150–300 分钟中等强度活动
- [《健康中国行动（2019—2030 年）》](https://www.nhc.gov.cn/guihuaxxs/c100133/201907/2a6ed52f1c264203b5351bdbbadd2da8.shtml) —— 全民健身行动、职业健康保护行动
- [《中国居民膳食指南（2022）》准则六](http://dg.cnsoc.org/article/04/wDCyy7cWSJCN6pwKHOo5Dw.html) —— 主动喝水、少量多次，每次约 200 毫升
- [美国验光协会（AOA）](https://www.aoa.org/healthy-eyes/eye-and-vision-conditions/computer-vision-syndrome) —— 20-20-20 规则；连续用电脑 2 小时后休息 15 分钟

所有提醒**都可跳过、可延后，不指责、不惩罚**。

## 目录结构

```
src/Core/     计量、存储、统计、成就、奖励、健康规则、音效、Win32
src/App/      计时引擎、状态门面、主窗口、外壳、快照渲染
src/Ui/       全部界面（即时模式，单窗口零弹窗）
src/Render/   绘图原语、缓动/弹簧/粒子、配色主题
src/Render/Art/  程序化番茄、图标、奖章
src/Tray/     托盘控制器、程序化托盘图标、ICO 打包
src/Assets/   图片接口（manifest + 热重载 + 回退）
Lang/         语言包（编译期嵌入，也可放在 exe 同目录覆盖）
assets/       可选的图片覆盖槽位
tests/        测试运行器与 721 项断言
```
